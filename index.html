A Warming World

Exploring Future Temperature Changes Across Regions

How do projected temperature changes vary across different regions under low- and high-emissions scenarios?

Writeup

Motivation

When climate change is being discussed, people often describe the warming as an increase in the global average temperature by 1 to 2 degrees Celsius. The problem with this is that nobody lives in this global average temperature. We only feel the temperature of the area we live in. Therefore, we're interested in investigating how much the warming projection changes from continent to continent to get a feel for what people will actually feel if climate change continues.

For each region, both low-emissions and high-emissions scenarios are displayed for comparison. This allows us to easily spot how the gap between the two scenarios changes from continent to continent as we switch between the graphs of different regions. Under SSP1-2.6 (the low emissions scenario), warming stays within about 1 degree of the baseline, which is defined as the average projected temperature of the years 2015 - 2034 (first 20 years of the data). Under SSP5-8.5 (high emissions scenario), the regions warm by about 2.5 to 4 degrees Celsius by 2100.

Data and Processing

Our data comes from CMIP6 climate model runs, which we accessed through NOAA’s public CMIP6 repository on Google Cloud. We used near-surface air temperature (tas) for two future scenarios, SSP1-2.6 (low emissions) and SSP5-8.5 (high emissions), from 2015 to 2100.

To aggregate data into regions, we defined each continent as a latitude/longitude box and averaged all the grid cells inside the box. To aggregate them into yearly values for the graph, we averaged temperatures into one value per year per region per scenario. To show changes relative to baseline, we subtracted the average temperature of the first 20 years (2015 - 2034), which is our baseline, from the data. This makes the graph show changes relative to roughly today's temperature, not the pre-industrial temperature commonly used elsewhere. We think this is more intuitive as readers can directly see how much hotter relative to today the Earth will become, instead of a pre-industrial temperature they feel no connection to.

Visual Encoding

  • Position for time and temperatures: We put time (year) on the x-axis and temperature change on the y-axis. This encodes time and temperature changes with position, which is the most effective visual channel for precise comparison. A continuous line chart is appropriate for sequential and continuous data to see how values change over time.
  • Fixed color for scenario: We used two distinct colors to separate the high-emissions from the low-emissions scenarios. We used orange for high-emissions and blue for low-emissions, which aligns with the intuition about warm and cold colors. We chose this over a continuous color gradient because the value itself is already encoded with position, making a color gradient redundant and even more confusing without any benefit.
  • Dashed zero line: The y=0 line is shown as a horizontal dashed line, which shows no change from the baseline average. This makes it easier to compare changes with the reference point.
  • Fixed y-axis: The y-axis stays the same across the graphs for different regions so that they're directly comparable.

Interaction

  • Region buttons (dynamic query): If we show all six regions on the same graph, there will be twelve total lines, which is hard to read. The buttons let the user pick a specific region and show the graph for that region only. The user can compare different regions by switching between the graphs of both regions, where the fixed y-axis ensures comparisons are accurate.
  • Animated transitions: When the user switches regions, the lines slide to their new positions instead of instantly appearing at their new location. This makes it easier to see how the data changed and how the trend moved between two graphs.
  • Tooltips (details on demand): When the user moves the cursor over the graph, a tooltip shows the year at the cursor and the temperature change of both scenarios at the same time. The user does not need to hover exactly on a line, because the graph reads where the cursor is horizontally. A faint dashed vertical line and two highlighted points (white fill with a colored outline) show which year is selected. This way we don't need to label every value, and the graph stays clean.

Alternatives Considered

We found all of these problems by actually using our graph after we built it.

  • Y-axis: At first we allowed the y-axis to vary based on the data, but then we realized that this made it difficult to compare between graphs because the y-axis kept changing and the trends looked the same even though the values were completely different. To ensure the graphs are actually comparable, we fixed the y-axis to a specific range that can cover all the data we have and allow for fair comparison.
  • Tooltip: At first, the tooltip only showed up when the cursor was on a single point and showed one scenario at a time. We found out this was hard to aim because the points are small, and hard to compare because we had to hover over both points again and again. So we changed it to show one tooltip for both scenarios whenever the cursor is in the graph.
  • Region selector: At first we used a dropdown to pick the region. We found out the dropdown list covers the graph when it opens, and the user has to click twice to switch regions. Since there are only six regions, we changed to one button for each region, so all the regions are always visible and switching takes one click.
